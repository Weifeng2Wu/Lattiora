# 原移动端 UI 的网页迁移

以 `b6320ce5 src/components/mobile` 为基准恢复列表、搜索、顶栏、侧滑返回、导航、抽屉及 PDF/Notes 切换。小于 768px 的首次加载默认使用原移动壳；`?view=mobile` 可显式选择，抽屉的桌面工作区入口切换 `?view=desktop`，完整原桌面文件树/多面板仍可使用。不随旋转强制重挂载应用，避免丢失编辑状态。

原桌面配对、Bridge RPC 和外部 ACP 后端选择不保留；使用相同 CloudGate 登录、IndexedDB 文件、D1/R2 同步及内置 AgentPanel。原移动端的简易聊天已由同一内置 Agent 消费者承接会话、Skills、文档工具与设置入口。移动壳也挂载完整设置/导入导出/同步控件，不创建第二套数据模型。

PDF 从缓存读取，沿用原 PdfViewer（批注/翻译/检索等）；没有缓存时明确提示，不发跨域 HEAD 冒充可读。PDF 与 Notes 在窄屏切换、宽屏并排；只实例化一份 PDF 阅读器，避免原 CSS 隐藏分支重复加载引擎。

原 textarea 与保存按钮保留。离开阅读页先保存，失败时停留；页面卸载对未保存编辑触发浏览器保护。保存校验最初读取的内容版本；若同步或另一标签页已经改动，保留旧文件到 `Conflicts/editor-*/…` 后写入当前编辑，双方均参与正常同步与备份。未保存草稿并非实时同步，仍需保存或使用返回按钮。

本地生产构建 Chromium 390×844 流程：原列表导入/打开真实 PDF、断网笔记编辑、返回保存、断网重载、联网实际 Worker 文件同步、独立标签编辑冲突双方内容保留、内置 Agent 导航。移动触摸真机、Safari、生产云端手机浏览器尚未验证。跨设备 CAS 覆盖复用 `cloud.spec.ts`，不把同设备双标签测试称作跨设备验证。
