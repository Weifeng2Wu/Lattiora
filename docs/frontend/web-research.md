# 关系图谱与全库语义检索

顶部存储工具栏提供「关系图谱」和「语义检索」，桌面作为可恢复的工作区标签打开，移动端使用独立视图并保留返回入口。两者复用 IndexedDB 工作副本，不需要另建云端向量库。

## 关系图谱

论文目录（PDF、NOTES 与 source）合并为一个论文节点，独立 Markdown 为笔记节点。连线区分已解析的 Wiki/Markdown 链接与文献引用；引用来自已有 `source/agentero-cite.json`，重新按当前库的 DOI、arXiv ID 或精确归一标题匹配。没有解析成功、目标存在歧义或已删除的引用不生成连线，不自动访问引文服务。

支持搜索、单节点邻居聚焦、两种连线开关、拖动节点、平移、缩放、适配画布及打开原文。键盘可选节点并使用打开/聚焦按钮。单次渲染上限 300 个节点，搜索和聚焦先应用于全部节点再限量，避免较大库的后续条目无法找到。文件变更后刷新；离线可读取已缓存的文件和引用。

## 全库语义检索

首次在 Agent 设置中配置 Embedding 服务，再点击「更新索引」。支持 PDF、Markdown、TXT、TeX、BibTeX、HTML 及批注中的文本，排除内部隐藏文件与根目录 Conflicts。检索覆盖率按当前文件版本和 Embedding 配置显示，未缓存或解析失败的文件单独列出；连续三项失败后停止，避免同一供应商错误反复请求。

正文分成约 1,800 字符的重叠片段，保存文件路径、行号及 PDF 页号。PDF 使用本地文本提取；扫描页明确显示部分覆盖，不自动调用付费 OCR。用户主动解析生成的 Markdown 等源文本也参与索引。搜索返回相似片段，最多 30 条、每文件最多三条；点击 PDF/批注命中可跳到论文相应页，普通文档打开原文（行号作为定位参考，尚不滚动到编辑器行号）。移动端独立文本来源以只读源码展示。

索引位于 `.agentero/search/<path-hash>.json`，包含来源 revision、模型标识和片段信息；向量复用推荐功能的 `.agentero/recommend/vectors/<model-hash>/<text-hash>.json`。增量更新仅处理有变化的来源，可取消，已完成文件保留。缺失向量的索引会失效；编辑、删除来源或更换 Embedding 配置后旧片段不作为当前证据返回。构建提交前及查询结束时再次检查来源版本，避免请求期间的编辑产生过期结果。

新片段和新查询会经现有登录 Worker 调用用户配置的 Embedding 服务，正文随请求发送至该服务；客户端不新增明文 Key。相同查询向量缓存后可离线复查。结果、索引和向量沿用 outbox/D1/R2 同步与备份，不承诺未缓存文件或新查询离线可用。

Agent 新增只读 `semantic_search` 工具，接受自然语言 query 和可选 prefix，返回命中及索引覆盖情况。工具只查询已建立的索引，批量建立索引由用户在界面主动触发；综合分析仍交给现有 Agent。

实现：`src/lib/cloud/{graph,semantic-search,embedding}.ts`、`src/lib/graph/model.ts`、`src/components/research/`。
