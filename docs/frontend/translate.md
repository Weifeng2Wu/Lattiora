# 网页翻译

原 PDF/选区翻译流程通过统一 Cloudflare AI 请求完成，供应商配置与右侧 AI 共用。翻译输入与目标语言由 Worker 构造相应模型请求；支持 Anthropic 和 OpenAI 兼容协议。

PDF 全文翻译需要先提取正文。文本页使用浏览器 PDFium，扫描页依赖视觉模型；无法读取的区域应报错，不能声称保留原原生版面模型效果。翻译结果及原 PDF marks 文件使用浏览器文件存储、同步与 ZIP 备份。

启用译文分栏后，点击全文翻译即打开并激活右侧译文页，尚未解析时自动排队解析，结果到达后自动开始翻译。原文与译文监听版面文件变化，即使后台解析完成时原文没有焦点也能读取结果。译文页由一个任务入口先读取缓存、保留已翻译段落，再处理其余页面；不再因缓存已有第一页而跳过后续页，也不依赖固定延时或第二次点击。

原文与译文可双向同步滚动、缩放；视口稍后挂载或替换时会重新连接滚动监听，并使用实际 DOM 内容尺寸，避免页面加载前缓存的零滚动范围阻止跟随。用户主动滚动后释放旧同步位置的回声标记，再次回到相同位置或页尾也会同步。点击原文不会把右侧可见译文切回笔记；手动切到笔记后继续使用原有论文/笔记联动。译文标签以原文面板 ID 配对，直接打开 PDF 文件时重复点击不会创建重复译文标签。

离线可以读取已保存结果，新翻译需要联网并产生模型费用。本次自动回归使用确定性翻译接口响应，未评估真实模型的语言质量与供应商限制。
