# 浏览器原版版面模型

原版 b6320ce5 使用 PP-DocLayoutV3（EmbedPDF ONNX），此模型不属于必须删除的原生功能。网页继续使用原算法、标签映射、0.3 阈值、侧栏/框选及正文富化，以 ONNX Runtime WASM/WebGPU 在设备端执行。

Layout 设置增加权重缓存状态、下载并测试、测试模型、上传原版权重入口。测试按钮运行真实推理，不仅判断 HTTP 200。模型无 API Key、无模型调用费用，不预设付费服务。Paddle/MinerU/独立 VLM 仍由用户设置其服务地址、模型及密钥。

权重来源沿用原 EmbedPDF 的 Hugging Face FP16 导出，固定 revision `0833193a430ce271aa434cf1eecfab19412ac6a0`，文件 `models/PP-DocLayoutV3-ONNX/model_fp16.onnx`，65,546,435 bytes，SHA-256 `e549a04370b88c3f26fe8a975d7f15d76cb15876b54588270c977426793445ad`。下载经登录保护的 `/api/layout-model` 流式转发，Worker 不缓冲整个模型，不接收任意来源 URL 或转发登录凭据。上传必须同样匹配大小与摘要；不能将任意 ONNX 误当兼容模型。

模型完整校验后存入设备 Cache Storage `embedpdf-ai-models`。每个设备首次下载一次，独立于用户文档/备份，不占 D1/R2 文档存储，也不随清理旧应用 shell 缓存删除。没有强制启动预下载；可先在设置下载，或首次使用本地分析时按需下载。权重上游不可达时可在能访问的网络下载同一文件，再在设置上传。源码不打包模型权重，使用其上游许可。

本地分析入口不再用文本框冒充图形检测：实际渲染 PDF 页，运行模型，再把坐标转换为原侧栏区域，补齐正文/图注，写入 `source/layout.json`（`embedpdf-layout`）及索引。每页渲染上限 2400 像素长边，避免超大页面分配失控。取消会丢弃结果并阻止持久化，但 ONNX 正在计算的当前页可能完成后才释放计算；浏览器内存不足/模型下载失败会明确报错，不退回假模型结果。

本地验证：真实公开权重下载成功；生产构建 + Wrangler + Chromium 在线推理及断网重启后再次推理通过。Worker 测试覆盖固定源和凭据隔离、错误长度拒绝。无付费模型参与；复杂论文检测质量、真实移动设备及云端下载验证需分别记录，不从空白测试页推断图形检测准确率。

追加 PDF 主流程验证：在离线状态导入真实生成的单页 PDF，通过原 Analysis 面板点击分析，检查保存的 layout.json 来自 `embedpdf-layout`、具有非空模型区域及提取正文。完整用例（在线下载/推理、离线重启推理、离线 PDF 解析）通过，耗时约 1.5 分钟。该测试验证数据链路，不代表复杂图表质量评测。

生产复验：0.18.0 Worker `ac4fbd40-33e8-4091-a318-51e31bf8f156` 上相同完整浏览器流程通过（约 1.7 分钟），包括真实云端权重下载与离线 PDF 检测；匿名下载返回 401。
