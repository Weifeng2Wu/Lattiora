# 浏览器 PDF 正文提取

原 PDF 工具栏的 Analysis 入口保留，动作改为“提取 PDF 正文”。使用 `src/lib/cloud/pdf.ts` 和 PDFium WASM 在浏览器读取文本及坐标，生成 `source/parsed.md`、`source/layout.json` 和布局索引，供文档上下文、阅读区域及翻译使用。

扫描页按 PDF 内容散列缓存视觉模型识别结果；首次识别需要联网和支持图像的模型，会产生供应商费用。错误会显示并保留已有文件，不用空结果假装成功。扫描识别质量尚未用真实模型验收。

原有图表/区域侧车可继续显示，但当前浏览器提取不等价于原 Rust/Paddle/精细 ONNX 图表模型。界面不承诺自动图形、表格、公式或引用提取。原后台模型下载、原生解析器安装入口已退出此分支。

实际 Chromium 验收覆盖了从原 Analysis 按钮提取文字 PDF，并检查正文落入持久化文件；见 [验证记录](../test/cloudflare.md)。
