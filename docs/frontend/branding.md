# Lattiora · 研织

Lattiora（研织）将论文、笔记和研究线索织成知识网络。应用使用 Lattiora 作为短名称，中文关于页使用 Lattiora · 研织。

## 视觉资产

![Lattiora](../assets/lattiora-icon.svg)

自绘 SVG 图形将打开的书页、交织线条和金色书脊结合。深松绿 `#123D38` 为底色，纸白 `#F6F1E5`、浅绿 `#A9C9B9` 为书页，暖金 `#D9B66F` 为书脊。图标自带底色，在明暗主题中使用同一资产；无需加载字体或外部图片。

应用资产为 `src/assets/lattiora-icon.svg`；文档副本为 `docs/assets/lattiora-icon.svg`。浏览器 favicon、登录、欢迎页、移动端、关于页及导出水印使用该图标。广场代理的导入按钮内联同一图形，修改图形时须同步该副本。
