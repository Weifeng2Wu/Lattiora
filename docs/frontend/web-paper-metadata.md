# 网页元数据编辑与刷新

原 Edit metadata 弹窗、单篇刷新和 Library 表头批量刷新保留。原批量刷新未迁移的 JobCenter 调用现由可取消浏览器活动执行：逐项查询、更新进度；失败继续其它项，成功部分保留，结束时报告未完成项。只接受唯一精确 lookup 结果，模糊标题搜索不自动覆盖现有论文；用户可在原弹窗指定 DOI/arXiv ID 后重试。

元数据与 NOTES 更新在同一 IndexedDB 事务提交，并校验读到的 metadata/NOTES 本地版本。远程查询开始前记录 metadata 版本，期间编辑或同步到新版本时拒绝旧结果。云端同步沿用普通文件 CAS；这不等于 metadata 和 NOTES 云端跨文件原子提交。

标题同步移植基准 `wiki/notes.rs`：保留全部旧别名并追加旧、新标题；仅更新与旧标题/文件名/URL stem 相同或通用占位标题的 H1。自定义 H1、正文及有内容的无标题笔记保留。只解析 aliases 区块，其余嵌套 YAML 属性保留。无法安全解析 aliases 时拒绝这次修改，不保存半套 metadata/笔记。标签与已读状态也使用同一 metadata 事务锁，避免并发全记录写入恢复旧字段；不改变原识别来源标记。

重新扫描目录时，已有论文内部的附件和源码插图不会被建成新论文。

验证见 `docs/test/cloudflare.md`。本批是原手动编辑/刷新消费者，不代表 PDF 自动识别、canonical 目录重命名或重复合并已完成；这些仍在迁移清单中。
