# Excalidraw、思维导图与 Kanban

在文件树的普通文件夹上右键，选择「新建思维导图」或「新建看板」，输入名称后回车。扩展名自动补全为 `.mindmap.json` 或 `.kanban.json`。文件在原 Dockview 工作区打开，也能通过 Quick Open 搜索。

## Excalidraw 白板

普通文件夹右键选择「新建 Excalidraw 白板」，名称自动补全 `.excalidraw`。使用官方完整单人绘图组件：形状、箭头、自由绘制、文字、图片、分组、层级、对齐、撤销/重做、素材库、画布缩放、网格与禅模式。主题与语言跟随工作台。画布聚焦时，剪切/粘贴、场景打开、缩放和元素链接快捷键交给 Excalidraw，避免误操作文件树。

- 图片通过插入、粘贴或拖入使用，图片数据随标准 `.excalidraw` JSON 的 `files` 一起保存、同步及备份，重新打开恢复。
- 使用原生菜单导入 `.excalidraw`、导出文件及 PNG/SVG；`Ctrl/Cmd+S` 保存工作区文件，底栏保存图标可重试。800ms 自动保存复用现有 `VisualDocumentSave` 串行写入器，后台切换/关闭面板尝试刷新，保存失败保留待写内容。相同场景变化不重复写入。
- 素材库共用 `.agentero/excalidraw/library.excalidrawlib`，使用相同 IndexedDB/outbox/冲突副本机制。支持本地素材库导入导出、从选区添加，以及通过官方素材网站安装。打开画布时读取最新已同步素材库；不同设备同时修改仍按整文件保留冲突副本。
- 绘图字体随构建部署并纳入 Service Worker 缓存，离线不依赖字体 CDN。浏览官方素材网站需要联网；安装允许连接 `libraries.excalidraw.com`。
- 损坏或不支持版本的画布进入 JSON 编辑视图，不自动覆盖为空白。每文件仍受工作区 32 MiB 上限约束。

本次范围为完整单人绘图，不包含 Excalidraw 托管云盘、多人实时协作及其付费 AI 服务。画布内外部网页嵌入继续受工作台 CSP 限制；普通外部链接可打开。

## 思维导图与 Kanban 编辑

- 思维导图：点击节点文本编辑并选中节点；工具栏添加子节点或同级节点、删除整个分支、选择父节点。分支可以折叠，内容保留。画布使用点阵背景与分支配色，根节点和当前选中节点突出显示，折叠节点显示隐藏的后代数量。使用与 Excalidraw 同类的 Rough.js 手绘节点和连线、柔和分支填色。支持滚轮平移、空白区域鼠标/触屏自由拖动平移（小导图也可拖动）、25%–150% 常规缩放、适应视图、定位选中节点和一键展开所有分支；适应视图可缩小至 5%。节点左侧把手支持拖动整个子分支，方向键每次移动 10 个画布单位；拖动松开后提交一次，可撤销，取消指针或 Escape 放弃拖动。工具栏颜色选择器设置当前分支颜色，子节点默认继承，可单独覆盖；提供恢复继承颜色与恢复自动布局。
- 新增节点会自动定位到可见区域并选中文本，可直接输入；选中节点右下角的加号就地添加子节点。编辑文本时 `Ctrl/Cmd+Enter` 添加子节点，`Alt+Enter` 添加同级节点，普通回车保留换行，中文输入法确认不触发快捷操作。底栏显示当前可见/总节点数。
- Kanban：默认包含待办、进行中、已完成三列，列名可修改，可增加、删除、左右移动列。卡片包含标题和描述，拖动卡片把手可跨列移动或插入到另一张卡片前；下拉框与上下按钮提供键盘和触屏操作路径。
- 工具栏提供撤销、重做、手动保存及 JSON 下载。删除分支或整列可用撤销恢复。撤销历史最多保留 50 步，仅在当前编辑会话有效；文本框中的快捷键保留浏览器原生文本撤销，工具栏撤销操作整个文档。
- 改动在 400ms 后自动保存到此设备，保存按钮可重试失败的保存；`Ctrl/Cmd+S` 立即保存。切换到后台或关闭面板会尝试提交待保存内容。云端状态继续由原同步工具栏展示。

## 文件与同步

文件使用版本 1 的普通 JSON：思维导图为 `type: "mindmap"` 与 `nodes: [{ id, parentId, text, collapsed?, color?, offset?: { x, y } }]`，唯一根节点的 `parentId` 为 `null`；看板为 `type: "kanban"` 与 `columns: [{ id, title, cards: [{ id, title, description }] }]`。数组顺序决定同级分支、列与卡片顺序。名称只决定文件路径，不绑定节点或列标题。

节点 `color` 为六位十六进制颜色，`offset` 为相对自动布局的偏移，后代累加祖先偏移；可选字段兼容旧文件。旧客户端不认识这些字段时会打开 JSON 修复视图，不会丢弃字段。位置和颜色复用相同的离线保存、版本同步和撤销链路。

编辑器复用文本面板的 `textSeed / textDirty / textKey`、`persistTextFile` 和文件刷新机制，不新增数据库表或 Worker API。写入仍走 `writeVaultFile` → `src/lib/cloud/files.ts` 的 IndexedDB、outbox、CAS 和冲突副本。每个编辑器串行提交，后续编辑使用上一次成功保存的内容校验；失败后保留待保存内容，不报告已保存。尚未保存的可视化文档参与文件移动的脏数据检查。

导入可使用原「导入文件到笔记」；单文件可下载 JSON，全库 ZIP 备份包含这些文件。完成应用缓存后的离线编辑与重载沿用 Service Worker；重新联网后恢复同步。未知版本、重复 ID、断开的树或循环引用不会被静默重置为空文档，而是打开 JSON 编辑器供修复。

本次范围是独立文档编辑，不包含从 Markdown 自动生成导图、论文引用知识图谱、AI 自动布局、拖动重设父节点和多人实时协作。复杂跨设备同时修改仍按整文件保留冲突副本，不合并节点或卡片。
