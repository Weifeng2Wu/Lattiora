# 网页 arXiv Daily 推荐

保留基准 b6320ce5 的 PlazaArxivRecView：分类、刷新、摘要翻译、阅读 PDF、入库。基准组件并没有此前审计误写的已读/隐藏/播客功能。

使用用户在设置中配置并测试的 Embedding 服务。最多取最近入库的 2000 篇有摘要论文，title + abstract 截至 4000 Unicode 字符，每批 64 条向量；按原算法归一化余弦相似度，以 `1 / (1 + log10(rank + 1))` 加权，默认返回 20 篇。API Key 仍由服务端加密保存；本地缓存标识只包含 URL 和模型名。调用产生用户供应商的模型费用，不附带免费模型服务。

`.agentero/recommend/state.json` 保存结果，vectors 子目录按配置与正文 SHA 保存向量，复用文件 outbox/D1/R2/备份。离线展示已缓存结果；联网打开时刷新过日结果；强制刷新也复用相同正文的向量。取消、供应商失败或途中更换配置不会覆盖上一轮结果。跨设备冲突仍采用通用文件 CAS/冲突副本。

arXiv RSS 通过登录保护的固定来源 `/api/recommend/feed` 读取，上限 16 MiB；通用订阅入口仍为 2 MiB。最多 20 分类、4000 候选、向量维度 8192、计算向量内存预算 128 MiB。任一分类失败会保留旧结果并报错，不会把不完整来源悄悄保存为完整推荐。该版本不提供推荐缓存专用清理界面；模型供应商原地改变维度时应使用新模型标识重新计算。

验证：本地单元测试覆盖原加权算法、维度校验、持久缓存、配置隔离、失败和取消保留；生产构建 + Wrangler 浏览器覆盖原 Embedding 设置测试按钮、原面板排序/刷新/入库、离线重启和重连同步。浏览器 feed/embedding/metadata 为 fixture，不能视为真实付费模型验证。本地 Wrangler 实际 arXiv cs.AI RSS 返回 200（约 3 MiB）。摘要翻译和 PDF 阅读复用既有消费者，本批浏览器用例未单独验收这两个动作。

回归发现并修复原 Embedding 表单在异步设置刷新时覆盖正在编辑字段的问题。浏览器现在强制核验结果缓存中的新模型标识及真实批次调用次数，避免误把旧推荐展示当成新配置成功。最终本地浏览器通过（38.2 秒）；取消保留已补单元测试。
