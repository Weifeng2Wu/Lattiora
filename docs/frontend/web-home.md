# 首页

顶部存储工具栏的房屋图标打开首页；移动端导航也提供「首页」。首次进入显示首页，此后记住当前浏览器上次停留的首页/工作区视图。桌面首页覆盖在原工作区上方，原 Dockview 和编辑器仍保留；「返回工作区」或打开文件恢复原文档。

关闭首页后无需刷新或重新打开网页：点击桌面顶部存储栏最左侧的房屋图标即可再次进入，移动端点击底部「首页」。返回工作区后原文档与面板布局继续保留。

默认显示当前设备时间、日期、论文总数、手动已读论文数、笔记数和阅读进度。论文来自现有 Library 数据；笔记统计工作区中存活的 Markdown 文件，排除内部目录和根目录冲突副本。时钟独立刷新，页面进入后台暂停更新。

## 会议截稿倒计时

「选择会议」可搜索会议简称、全称和年份，并按 CCF 等级、研究领域筛选、多选。默认提供各会议最新一届，以及仍有未来截稿轮次的往届；选中后首页按最近的未来全文截止时间排序，在可独立开关和排序的会议组件中以紧凑列表仅显示会议名称（含年份）、全文截止日期和天数/时分秒倒计时。每行名称与倒计时并排、日期位于第二行，窄屏顶部区域纵向排列；会议名称可打开官网，行末按钮可取消关注。

数据来自 [CCF Deadlines](https://github.com/ccfddl/ccf-deadlines) 的公开 `https://ccfddl.com/conference/allconf.json`（上游 MIT 许可），复用已登录的 `/api/feeds/fetch` 代理及其超时、响应大小限制，不增加后端接口或客户端跨域权限。初次在线进入加载，缓存超过 24 小时后再次进入自动更新，重连或点击刷新也会更新；选择会议弹窗底部显示来源及上次成功获取时间。截止日期以会议官网为准。

倒计时根据数据源时区计算：AoE 为 UTC−12，固定 UTC 偏移直接换算，PT 根据 `America/Los_Angeles` 夏令时换算；界面日期显示设备本地时区，全文时间悬停可看源时间及其时区。摘要截止不在首页展示，摘要过期不误切换全文轮次。全文过期后切换到下一轮，全部截止显示「投稿已截止」；TBD、无效日期或无法确定的时区不生成虚假倒计时。源移除的已选条目保留取消入口。

会议目录缓存在现有 IndexedDB 的独立 `state` 项，所选会议为 localStorage 浏览器偏好；与首页看板选择一致，**不跨设备同步，也不写入工作区文件或 outbox**。已加载的目录及选择支持离线刷新和取消关注；首次未缓存时需联网加载。更新失败保留原目录并使用 Toast 提示。倒计时与首页时钟共用可见性计时 hook，进入后台暂停界面更新，返回后按真实时间重算；秒级更新不会重绘会议选择器或待办。

实现：`src/components/home/conference-countdowns.tsx`、`src/lib/cloud/conferences.ts`、`src/lib/cloud/conference-deadlines.ts`、`src/hooks/use-visible-now.ts`。

验证：`test/cloud-conferences.test.ts` 覆盖 AoE/UTC/PT 夏令时、无效日期、多轮边界、摘要与全文区分、同简称会议、失败保留缓存及不污染文件/outbox；`test/browser/conference-countdowns.spec.ts` 在生产构建 + 隔离 Wrangler/Chromium 验证筛选、多选、键盘、秒级变化、TBD、刷新失败、离线重载/取消和 390px 布局。浏览器会议响应使用受控 fixture；另通过真实上游与本地 Worker 读取 374 个会议、2,301 届记录，全部非 TBD 全文日期可解析（2026-10-06）。

会议组件内部沿用紧凑列表；外层尺寸与位置由首页布局设置决定。

## 看板待办

待办直接使用普通 `.kanban.json` 文件，可选择看板、添加任务、勾选完成、展开已完成任务后重新打开；桌面「打开看板」进入原可视化编辑器。没有看板时，首次添加任务会在 `notes/` 创建独立看板。任务进度和待办计数针对当前选中的看板，不代表全库任务量。

「完成列」默认仅识别唯一的 Done / Completed / 已完成列；可手动指定。未选择完成列时不能勾选完成，进度保持零；不会按列顺序猜测完成状态。选中的看板和完成列是当前浏览器的视图偏好。新增任务进入第一个非完成列，取消完成也返回该列。

任务修改复用 IndexedDB、outbox 和云端 CAS；写回前检查看板快照版本和打开编辑器的未保存状态。有新编辑则保留输入并 Toast 提示，不覆盖文档。离线可新增/完成，恢复联网后同步。损坏或未缓存的看板保留原文件并提示，暂不纳入待办列表。

实现：`src/components/home/home-page.tsx`、`src/lib/cloud/home.ts`。

首次引导结束时，异步文件扫描会重新检查最新设置，避免过时的检查结果再次打开引导并遮挡首页入口。

验证：生产构建 + 隔离 Wrangler/Chromium 的 `test/browser/home.spec.ts` 通过首页与工作区往返、离线任务增改/刷新、重新联网同步及 390px 手机显示。首次引导辅助流程确认关闭结果，存储状态断言限定到存储工具栏，避免误匹配 Agent 工具栏。

## 自定义组件与背景（0.37.0）

首页卡片顶部的拖动手柄可直接排序，目标卡片高亮，松手自动保存；靠近滚动区域边缘会自动滚动。鼠标悬停或键盘聚焦显示手柄，触屏常驻显示。也可聚焦手柄后使用方向键逐项调整、Home/End 移至首尾，Esc 取消拖动。

「自定义首页」可逐项开关、向上/向下排序，并选择小、中、全宽。原有时钟、会议倒计时、四项统计、阅读进度、任务进度和待办均为独立组件。

网格按首页实际可用宽度（含侧栏影响）切换一、二、四列；同一行的卡片自动等高。时间和计时字号按卡片宽度缩放，长城市名/标题换行，窄待办将选择器和状态分行，会议倒计时在窄卡片内改为纵向排列。13 个组件均支持小、中、全宽及窄容器，保留内容与操作入口，不依赖截断卡片来消除溢出。新增组件默认关闭：

- 最近阅读：按实际阅读时间排序的最近五篇论文，显示浏览页数并打开论文。
- 专注计时：1–120 分钟，可开始、暂停、重置；当前设备保存截止时间，后台或刷新后按真实经过时间计算，结束 Toast 提醒。
- 天气：手动搜索并选择全球城市，或在「自定义首页」的天气位置设置点击「使用当前位置」，浏览器授权后点击「保存布局」。定位显示为「定位地点」，经纬度保留两位小数，沿用城市设置跨设备同步；仅在点击时获取一次，不持续追踪，移动后可再次点击更新。拒绝授权、超时或浏览器不支持时 Toast 提示并保留原城市，可继续手动选择。城市名称/别名由 Open-Meteo 提供，不限制国家；部分中文译名可能无匹配，建议尝试英文或当地名称（如 London、Tokyo）。使用登录保护的 `/api/weather/cities` 和 `/api/weather`，只代理固定 Open-Meteo 地址；显示当前温度、天气、高低温、更新时间和来源。进入时缓存超过 30 分钟则更新，重连或手动刷新也可更新；离线保留最近一次数据。

组件选择参考 [Homepage widgets](https://gethomepage.dev/widgets/)；天气接口及来源为 [Open-Meteo](https://open-meteo.com/en/docs)，无需额外 API Key。

背景允许上传 PNG/JPEG/WebP（最多 12 MiB），在浏览器缩放到最长边 2,560px 并转换为 WebP；模糊 0–30px、遮罩 0–95%。布局、城市和背景参数保存于 `.agentero/home/settings.json`，图片在 `.agentero/home/backgrounds/`，使用现有文件同步及版本检查。新设备先收到配置后收到图片时会重新加载图片。离线可修改与重开；并发修改不会无声覆盖。拖动只在松手后写入一次，使用拖动开始时的版本；保存失败会恢复已保存布局并 Toast 提示，取消拖动不产生写入。

会议关注列表、所选看板/完成列、专注计时仍是当前浏览器偏好；组件布局与背景跨设备同步。移除背景仅取消引用，已有图片仍随工作区备份保留。

阅读进度按各论文的实际浏览页数 / 总页数计算，再取所有论文的平均值；手动标记已读的论文贡献 100%。未访问的论文为 0%，AI 分析不增加阅读百分比。计数和详细规则见 [阅读记录](web-reading-heatmap.md)。

## 闪念胶囊

「自定义首页」可启用闪念胶囊。输入最多 10,000 字符，输入框内点击保存或 Ctrl/⌘+Enter 新建一条普通 Markdown 笔记，路径为 `notes/quick-captures/<时间>-<随机标识>.md`。组件显示最近五条，可打开原文继续编辑；未发送草稿仅在当前浏览器保存。失败保留输入，成功后清空。发送按钮的提示包含快捷键；目前没有全局唤起快捷键。

已保存记录沿用工作区离线写入、outbox、跨设备同步和备份；语义索引下次更新时自然包含这些笔记，Agent 也可直接读取。不会自动调用 AI。普通笔记和论文 NOTES 的三种视图见 [Markdown 编辑与渲染](markdown-views.md)。
