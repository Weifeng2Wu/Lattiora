- AI：统一 Anthropic/OpenAI-compatible 配置取代本机 Agent 安装；原个人提示词、响应语言、精读/PDF 问答模型设置保留。原 Agent 面板与文档工具消费者见 [web-agent](web-agent.md)。

## 测试连接

所有配置服务均有可重新执行的测试按钮。统一 AI 发短文本请求（最多 16 输出 token），翻译发短文本，Embedding 请求向量，EasyScholar查询示例刊物；Paddle 提交微型 JPEG OCR 任务，MinerU请求空文件列表检查鉴权，OpenAI-compatible解析服务读取 `/models`。后两种不能证明实际 PDF 解析质量或指定视觉模型可调用；实际 OCR 在解析任务中验证。连接测试可能消耗供应商额度，尤其 Paddle 会创建任务。

AI、翻译与解析连接测试可以检查当前输入，草稿 key 不写入本地存储。EasyScholar 使用已保存 key。保存和探测是不同操作；失败不会标记连接成功。

## 设置同步与密钥

冲突副本统一在「同步 → 处理冲突」比较与恢复，工作区文件树及搜索不再显示根目录 `Conflicts/`。原版本继续保留在同步数据与备份中，详见[冲突副本管理](web-conflicts.md)。

Doctor 的双链语义探测提供可编辑替换行；修改绿色行后自动勾选，歧义文件可从候选下拉框选择。未改变的项不参与「修复」。提交会重查文件哈希、未保存编辑和替换后的实际链接解析；缺失、歧义或无效锚点仍未解决时整批拒绝写入，通过 Toast 提示，不原样写回后报告成功。仅修改选定的 UTF-8 字节区间，保留中文、别名与周边正文。

非敏感偏好以 `.agentero/settings.json` 同步，经过 IndexedDB/outbox/CAS，离线可改。版本冲突保留 `Conflicts/` 副本。服务 key 只通过在线 `/api/settings/secrets` 保存到 D1，AES-GCM 加密，每个槽位独立 AAD 和版本。读取只返回配置状态/版本；浏览器快照及普通备份只有固定掩码，不含明文。带确认按钮的 Key 保存失败保留输入以便重试；Embedding 使用原失焦保存交互，失败保留输入并提示错误，成功后显式恢复掩码。Key 不进入离线队列。

新设备首次登录先拉取工作区及设置版本，再开放编辑，避免默认设置与初次同步发生冲突。已有可信设备从本地缓存启动，离线编辑无需等待服务器。

旧版本 localStorage 中可能存在的明文服务 key 不自动上传，迁移时清除并要求重新输入。清除浏览器站点数据也会清除尚未同步的偏好、文档及本设备阅读统计。

迁移欠项仍以 [逐项审计](../development/migration-feature-audit.md) 为准。本页面不代表全部原功能已迁移完成。

## 0.14.0 服务地址与默认翻译

默认翻译使用用户配置的统一 AI。腾讯交互翻译、Google Translate 和 Google Translate (API) 预置免 Key 公共端点，可直接选择；自定义地址优先，留空恢复默认。腾讯端点为 `https://transmart.qq.com`，Google 为 `https://translate.google.com` / `https://translate.googleapis.com`。火山、DeepLX 和商业渠道仍需填写 endpoint；商业渠道另填 Key 和必要的 region/model。没有默认地址且未填写地址时不发送外部请求。公共接口可能限流或拒绝，连接测试使用实际翻译请求。打开渠道菜单不批量探测。

翻译渠道下拉框与 API 卡片的状态点：配置齐全为绿色（已配置），未配置为灰色；测试中为黄色，成功为绿色（可用），失败为红色。重新打开设置会依据配置恢复颜色；配置状态不代表已通过连接测试。
