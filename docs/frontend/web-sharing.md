# 链接分享

笔记工具栏的「分享与导出笔记」分为下载和链接分享。下载保留 PDF、PNG、Markdown 格式；链接分享不选格式，接收方直接阅读排版后的 Markdown 正文、公式、表格和代码。分享发布当前编辑内容的只读快照，后续编辑不会更新已发布的副本；frontmatter 不公开。

笔记包含其他笔记链接时，创建区会询问「是否同时分享链接到的笔记？」并逐篇列出，默认均不勾选。只将主笔记和勾选的直接关联笔记打包进这次分享，接收方可在它们之间跳转及返回。未勾选、无法明确解析的链接仅显示文字；关联笔记中的更深层链接不会自动公开。普通外部网页链接仍可打开。解析复用工作区双链规则，支持 Wiki 链接与 Markdown 本地链接，跳过代码中的示例。所有选中笔记都去除 frontmatter，共用一个密钥、有效期和关闭状态。

创建时可选择无需密钥或设置 4–128 字符的访问密钥（开启时自动填入随机密钥），有效期为 1/7/30 天、永久或自定义日期。密钥与链接分别交给接收方；服务端只保存加盐哈希，不提供密钥回显。默认无需密钥、7 天有效。需要换密钥、有效期或内容时，关闭旧链接后重新创建。

重新打开同一笔记的链接分享页，可复制或关闭已有分享；顶部存储栏「导出 → 管理分享」列出所有未关闭分享，源文件改名或删除后仍可关闭。关闭立即撤销主笔记及所选关联笔记的后续访问，删除该快照的 R2 对象，并从两处管理列表隐藏；刷新或重开不会重新显示。D1 保留关闭记录。到期仅禁止访问，不自动删除对象，列表仍保留，可关闭过期分享以释放其存储。

接收方打开 `/share/<随机 ID>`，无需工作区登录。无密钥时直接显示正文，有密钥时先验证；关联笔记使用同一分享页的 `#note=<序号>` 导航，不读取原工作区。阅读器复用 Streamdown 与 KaTeX，禁止执行原文 HTML，不加载工作区相对图片或私有 API；本地附件未额外打包，公开网络图片可显示。既有 0.30.0 PDF/PNG 链接继续按原方式预览和下载，旧 Markdown 链接改为正文阅读。

分享页不初始化工作区、IndexedDB 或离线缓存。内容 API 使用 `no-store`，每次访问都检查到期与关闭状态；已打开页面每 30 秒或切回页面时复查。已接收的副本无法远程收回。创建、管理和读取链接需要联网，失败用 Toast 或接收页状态反馈。普通文件保存、outbox/CAS 和离线下载导出不变。

整份分享（含选中笔记）上限 16 MiB；分享是额外的 D1/R2 服务记录，不包含在工作区文件 ZIP 中，服务灾备需要同时备份 D1 和 R2。新笔记快照使用带版本号的 JSON，在既有 `md` 记录对应的 R2 对象中以 `application/vnd.agentero.note+json` 标识，后端验证结构。无需新增 SQL、Secret 或绑定；初次安装仍需 `0005_shares.sql`。

实现：`src/components/cloud/share-panel.tsx`、`public-share-page.tsx`、`shared-markdown.tsx`、`src/lib/cloud/note-share.ts`、`shares.ts`、`cloudflare/shares.ts`。公开 API 仅能访问独立快照，不开放 `/api/file`、文件列表或其他工作区能力；创建、列出、关闭仍要求原登录会话及写请求 Origin 检查。
