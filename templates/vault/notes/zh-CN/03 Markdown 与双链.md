# Markdown 与双链

Lattiora 的笔记就是普通 Markdown 文件。你可以在应用内编辑，也可以用任何外部编辑器打开。

## 基础 Markdown

```markdown
# 一级标题

## 二级标题

- 项目符号
- 另一个项目

1. 编号列表
2. 编号列表

**粗体**，*斜体*，`行内代码`
```

```rust
// 代码块
// 点击右上角按钮切换语言类型, 或者复制代码块内容
```

> [!NOTE]
> 支持 Obsidian 风格的 Callout。

Callout 会渲染为带图标和主题色的块。点击标题或左侧图标可就地编辑类型和标题。支持的类型包括 `note`、`tip`、`info`、`warning`、`danger`、`success`、`question`、`quote`、`example` 和 `failure`。

## 公式

行内公式：`$E=mc^2$`

块级公式：

```markdown
$$\int_a^b f(x) dx$$
```

> [!TIP]
> 输入 `\$a\$` 会保持为普通文本；`$a$` 会渲染为公式。

## Slash 命令

在编辑器中输入 `/` 打开轻量命令菜单。用方向键选择、`Enter` 插入。命令包括标题、列表、待办、引用、代码块、图表、链接和 Callout。

常用命令：

| 命令           | 插入                                 |
| -------------- | ------------------------------------ |
| `/mermaid`     | 实时渲染的 Mermaid 图表              |
| `/code`        | 代码块（从语言选择器选语言）         |
| `/callout`     | Obsidian Callout（默认 `note` 类型） |
| `/link`        | 内部双链 `[[]]`                      |
| `/heading 1–3` | 标题块                               |

> [!NOTE]
> `/` 必须位于行首或紧跟空格。在代码块内或双链补全菜单打开时不触发。

## 外部链接

编辑器支持标准 Markdown 外链：

```markdown
[Lattiora 官网](https://example.com)
```

手写完整的 `[文字](链接)`（打完最后的 `)` 会变成链接）、直接粘贴同格式，或用右键 / Slash 的 **新增外部链接**（会插入带占位文字的链接节点并打开编辑气泡，填写显示文字与地址）均可。单击已有链接可再编辑；**⌘/Ctrl+单击**、中键或右键用系统浏览器打开。指向 Vault 内其它笔记的相对路径仍走应用内跳转。

## Mermaid 图表

用 `/mermaid` 插入，或在代码块的语言选择器中选择 **Mermaid**。图表预览会显示在源码下方：

```mermaid
graph LR
    A[论文] --> B[阅读]
    B --> C[笔记]
    C --> D[下一步]
```

> [!TIP]
> Mermaid 图表是只读预览 —— 修改上方源码即可更新图表。

## 双链

用双方括号链接到另一篇笔记：

```markdown
[[01 论文导入与管理]]
```

链接到笔记中的某个标题：

```markdown
[[01 论文导入与管理#论文库（Library）]]
```

嵌套标题使用完整路径：

```markdown
[[01 论文导入与管理#导入方式#Zotero Connector 插件]]
```

用 `@` 链接 PDF 划词 / 视觉批注（`id` 可从批注面板复制，或输入 `[[@` 补全）：

```markdown
[[@批注id]]
[[papers/…/NOTES@批注id|论文标题]]
```

- `#` 标题 · `^` 文本块 · `|` 显示名 · `@` 批注；`tab` 补全 · `enter` 确认。
- 批注 target 用路径（`NOTES` / `paper.pdf` / `papers/…/NOTES`），不要只用论文展示标题。

Lattiora 会索引所有 `[[...]]` 双链，用于 **Backlinks** 面板和 **Graph** 视图。

## 嵌入

在双链前加 `!` 即可将其内容嵌入为只读块：

```markdown
![[01 论文导入与管理#论文库（Library）]]
![[papers/…/NOTES@批注id]]
```

可以嵌入：

- **笔记区段** — 任意标题路径：`![[笔记#标题#子标题]]`
- **图片** — `![[示意图.png]]` 或 `![](./assets/示意图.png)`
- **PDF 页面** — `![[论文.pdf]]`
- **PDF 批注** — `![[…@批注id]]`

嵌入内容与源文件保持同步。编辑原始文件后，所有嵌入会自动更新。嵌入块本身是只读的 —— 要修改内容请编辑源文件。

## 图片

在 Markdown 笔记中粘贴图片，Lattiora 会自动把它存到该笔记的 `assets/` 文件夹：

```markdown
![示意图](./assets/diagram.png)
```

如果图片不再被引用，会被自动清理。
