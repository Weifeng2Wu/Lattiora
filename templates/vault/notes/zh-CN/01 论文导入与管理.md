# 论文导入与管理

## 论文库创建

## 导入方式

Lattiora 支持多种导入方式，导入你的论文。

### 魔棒入库

1. 点击侧边栏的魔棒按钮粘贴
2. 把你需要的链接粘贴到输入框当中。Lattiora 会下载元数据和 PDF 到新的论文文件夹。
    - arXiv ID
    - DOI
    - 包含这些标识符的学术网页链接

### Zotero 导出

从 Zotero 导出 BibTeX、RIS 或 JSON，再使用工作区工具栏的 **导入**。浏览器应用不能代替 Zotero 的 localhost Connector 监听服务。

### 网页来源

在魔棒粘贴公开文章 URL，可导入元数据和可读正文。arXiv ID 与 DOI 使用对应学术元数据服务。HTML 来源可在 HTML 视图阅读和缓存；需要登录或完全由客户端脚本生成的页面可能无法提取正文。订阅文章也可从 Feeds 入库。

### 本地 PDF

把 PDF 拖进文件树，或使用导入命令从本地文件创建论文文件夹。

## 论文库（Library）

Library 表格展示 catalog 中的所有论文。你可以：

- 点击表头排序。
- 右键表头选择显示列并拖拽排序。
- 按标签筛选，或搜索标题、作者、摘要、标签子串。
- 点击 **Rescan** 补齐盘上有但 catalog 中没有的论文文件夹。

### 打标签

在左下角的 **Info** 面板增删标签。标签保存在 每篇论文的 `.paper.json` 中，并以彩色 chip 显示在 Library 里。
